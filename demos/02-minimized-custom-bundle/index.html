Releases

Releases move through staging before reaching production. Builds tagged STABLE can be promoted immediately; those tagged RC need sign-off from a second reviewer, and anything marked YANKED blocks the pipeline until the issue is resolved.

STABLE

v1.4.2 — Production

Bundle sizes are down 4 % after switching the icon font to glyph-level subsetting. No API changes; existing integrations can upgrade without migration.

RC

v1.5.0-rc.1 — Staging

Introduces a $semantic-color-additions hook for extending the palette without forking the config. Two integration tests are still running — hold off on promotion until the visual-regression suite clears.

YANKED

v1.5.0-beta.3

A minifier ordering change broke the custom-property snapshot baseline. Artefacts are quarantined; the fix is merged into main and will ship with rc.2.
