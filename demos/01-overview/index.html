main

Motivation

Modern and lightweight CSS framework providing a good but small foundation for all types of web applications using the Flexible Box Layout module (Flexbox).

We provide ready-to-use frontend components and layout helpers that are easily combinable to build responsive web applications. Light and dark mode agnostic designs are supported out of the box.

The framework is free to use and optimized for size and load speed. All color and typography choices are easily customizable to your needs.

There is no mandatory Javascript. Modals, accordions, dropdowns, the navbar menu, toggle buttons and even the theme switch in the corner of this page all run on native browser features – <dialog>, <details>, popover and :has().

The single script on this page reads the picked file’s name out of a file input, which no stylesheet can do. Nothing else here needs one.

Download and Usage

Link a pre-built file from a CDN – @1 follows the latest release of this major version:

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/nuvio@1/dist/nuvio.min.css" />

For production, pin an exact version and add its integrity hash – the notes of every release list them, next to a zip of all 16 files to download.

Or install the package and import the stylesheet once, in your application’s entry point – the README shows where for Vite, Next.js, Nuxt, Angular and SvelteKit:

npm install nuvio
import 'nuvio/dist/nuvio.css'

To change colors, typography, breakpoints or the set of components, compile Nuvio from its Sass sources instead:

@use "nuvio/src/config" with (
  $semantic-color-excludes: ("bright", "dim"),
);
@use "nuvio/src/includes-full";

Everything on this page works from Chrome and Edge 135, Firefox 147 and Safari 26.2 on.

Builds as Small as 19 KiB (Base Feature Set)

Nuvio comes as 16 pre-built files: two feature sets in four theme modes, each minified and unminified. The full set holds every component on this page. The base set keeps the layout, the 12-column grid, spacing, boxes, notifications and four semantic colors – enough structure for widgets and server-rendered pages.

The theme mode decides how much of the color system ships: auto follows the system setting and can be overridden, prefer only follows it, light and dark carry one palette each.

Container System

The .container class allows designing and responsively aligning the same content for different viewports, devices and screen sizes. They add horizontal padding and keep content from touching the viewport edges and step through max-widths at each breakpoint. There are also fixed-breakpoint variants that lock the container at one specific viewport’s max-width.

In contrast, the .container.is-fluid modifier always spans the full viewport width for maximizing design space.

Nuvio has a biased opinion on which responsive viewports are really relevant in the year 2026, featuring no viewports without actual relevance, a steeper progression between viewports and a larger final viewport. All customizable to your needs though, of course.

Tabular Numbers

Proportional digits differ in width, so a value that changes in place – a live reading, a counter, a clock – shifts sideways as its digits change, and figures in a column do not line up. .has-tabular-nums gives every digit the same width, where the font provides tabular figures.

Some fonts already set their digits tabular by default, and there the two panels below look alike; with a font whose default digits are proportional, the left column's figures do not line up.

Pairing & .is-spaced

A title or subtitle carries .75rem of bottom margin. When another heading follows immediately, that gap collapses so the pair reads as one unit: title + title drops to .6rem, title + subtitle and subtitle + subtitle drop to 0.

Add .is-spaced to opt out and keep the full baseline margin. The rule matches on the adjacent sibling – anything between the two headings, including a wrapper element, breaks the pairing.

Margin & Padding Modification

Fine-grained adjustments using a non-linear scale 0–8. Small steps give fine control; large steps give structural jumps.

Prefix m for margin, p for padding. Append t/b/l/r for single sides, x for left & right, y for top & bottom, or nothing at all for every side. m-auto, mx-auto, ml-auto, mr-auto for centering – auto exists for margins only. Same scale is used for the flexbox and grid gaps.

s and e are the flow-relative counterparts of l and r: ms-3 / me-3 / ps-3 / pe-3 address the inline-start and inline-end side, so they swap over under dir="rtl" while ml-* and mr-* stay on the physical left and right.

We combine the definitions of a flex container, flex direction, flex wrapping, and a default row and column gap in one class for a set of usual use cases.

Class naming: row / col = no wrapping; rows / cols = wrapping. Suffixes: -stretched = children grow & shrink equally; -spaced = space-between; -leading = flex-start; -trailing = flex-end.

Dropdowns

A dropdown pairs a .dropdown-trigger with a .dropdown-menu.

Nuvio uses the modern Popover API to implement this without Javascript. Put popover on the menu and point the trigger’s popovertarget at it. Opening, closing, click-outside dismissal, Esc, top-layer stacking and the trigger’s expanded state are all handled by the browser. Nuvio anchors the menu under its trigger or flips it above when there is no room below.

Items work as <a> or <button> – both are first-class selectors and render identically, so use a <button> whenever the item triggers an action rather than navigating. A bare <div class="dropdown-item"> stays a static label.

Baseline Nudging

Icon fonts draw their glyphs at slightly different baselines. Nuvio has a framework-wide correction living in the $text-icon-y-compensation and $button-icon-y-compensation config knobs at built time.

In addition to that there are six classes .yc-up1 … .yc-down3 that allow a per-icon correction at use time on top of it, in ±0.5px steps. Look at the examples closely, as this is deliberately very subtle.

They are implemented as transform, so they never change the line height or the button height. The same class shifts by a different amount inside a .button – always tune a button icon against a button, and a text icon against text.

Navbar

The Navbar component features a customizable navigation bar that can be placed anywhere in the page flow or fixed at the screen top or bottom.

It has an optional .navbar-brand for a brand image or text and can have two .navbar-menu children .navbar-start (placed on the leading side of the bar) and .navbar-end (on the trailing side). The menus have .navbar-item entries that can be text, anchors, dropdowns, buttons, other form components or basically anything.

The menus collapse below the sm breakpoint (configurable), rendering a burger button that on tap shows all .navbar-item entries in rows.

A .navbar-item.is-dropdown holds a submenu. With .is-hover, on mouse controlled devices, it opens on hover instead of on click.

Fixed to the Viewport

.is-fixed-top and .is-fixed-bottom pin the bar to the screen edge. Because a fixed bar is out of flow, the page has to reserve the space itself – add .has-navbar-fixed-top or .has-navbar-fixed-bottom to the <body>. That padding follows the navbar’s size modifier automatically.

Hoverless .is-hoverless

Suppresses the hover and focus background on a.navbar-item – for bars that are pure branding, or where the items already signal state some other way. It leaves .navbar-link dropdown triggers alone, and applies from the navbar breakpoint up; on mobile the navbar has no item hover background to begin with.

Native Validation – :user-invalid / :user-valid

Constraint validation attributes are enough: fill these in, then leave the field. .input, .textarea and .select select pick up the danger border while the value is invalid and the success border once it is valid. .is-fullwidth.has-name

.has-name.is-empty – the filename slot is hidden until a file is picked

A JS-toggled state: ship is-empty alongside has-name, then remove it once the input reports a file. .is-empty on its own does nothing – the rule only matches in combination with .has-name. Pick a file below to watch it resolve.

A file input does not reveal the chosen filename to CSS, so .has-name is the one place where Nuvio expects a few lines of script. This page runs exactly these:

document.querySelectorAll('.file-input').forEach(input => {
  input.addEventListener('change', () => {
    const files = Array.from(input.files);
    const fileEl = input.closest('.file-label').parentElement;
    const nameEl = fileEl.querySelector('.file-name');
    if (!files.length || !nameEl) return;
    nameEl.textContent = files.length === 1
      ? files[0].name
      : `${files.length} files selected`;
    fileEl.classList.remove('is-empty');
  });
});
