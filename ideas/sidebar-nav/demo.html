sidebar-nav

From 769px up the sidebar is a full-height rail; the first control in its footer, at the bottom left, collapses it to a bar of icons, where each label flies out on hover or keyboard focus. Below 769px it is a top bar whose burger opens the navigation as a popover. Resize to try both.

The collapsed state is a checkbox, so it needs no script – and is forgotten on the next page unless the application renders it checked. See README.md.

Page content fills the rest of the width and grows when the sidebar collapses.
